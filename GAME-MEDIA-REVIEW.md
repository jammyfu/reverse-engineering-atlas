## Cover policy

A commercial game cover can identify a game, but cannot demonstrate the reverse-engineering project's output. Only add it with verified reuse terms and an explicit “game cover, not project screenshot” caption. A later official press-site check established a limited non-commercial editorial license for the Pokopia key visual only. Recompia now uses that unmodified official thumbnail, explicitly labeled as game art rather than project output; see `images/editorial/README.md`. No usable cover permission was established for the other five rows. Existing repository cards remain clearly source-labeled and are not upgraded into “game screenshots.” Only the officially licensed Pokopia thumbnail was added; no other third-party game media was copied or hotlinked. Follow-up cover additions must record exact source, rights holder, permission evidence, file checksum and purpose.
